## 📌 Project Overview

This project demonstrates a complete end-to-end data analytics workflow, starting with the definition of a business problem and ending with the presentation of data-driven insights and recommendations to stakeholders.



## 📍 Project Roadmap

| # | Stage | Tool |
|---|---|---|
| 01 | 💼 Business Problem | Business Analysis |
| 02 | 🐍 Data Modeling & EDA | Python |
| 03 | 🗄️ Data Storage | SQL |
| 04 | 🔎 Data Analysis | SQL |
| 05 | 📊 Interactive Dashboard | Power BI |
| 06 | 📝 Project Report | Documentation |
| 07 | 🎤 Stakeholder Presentation | Gamma |

## 🔎 Project Details

<details>
<summary><strong>01. 💼 Business Problem</strong></summary>

A leading retail company wants to better understand its customers' shopping behavior in order to improve sales, customer satisfaction, and long-term loyalty. 
The management has noticed changes in purchase patterns across demographics, product categories, and sales channels (online vs offline). They want to uncover which factors, such as discounts, reviews, seasons, or payment preferences, drive consumer decisions and repeat purchases.

The goal is to analyze the company's consumer behavior dataset in order to answer the following business question:

"How can the company leverage consumer shopping data to identify trends, improve customer engagement, and optimize marketing and product strategies? "

</details>

<details>
<summary><strong>02. 🐍 Python — Data Modeling & EDA</strong></summary>

Python will be used as the primary environment for raw data ingestion, preparation, modeling, and exploratory data analysis (EDA).

The initial exploration focuses on understanding:
- Data dimensions
- Column names
- Data types
- Missing values
- Duplicate records
- Numerical distribution
- Categorical variables

The raw data is prepared for downstream analysis by addressing common data-quality issues such as:
- Handling missing values
- Removing duplicate records
- Correcting data types
- Standardizing column names
- Handling inconsistent categorical values
- Identifying outliers
- Validating business rules

</details>

<details>
<summary><strong>03. 🗄️ SQL Database</strong></summary>

After the data has been cleaned and prepared in Python, it is loaded into the MySQL database.
This will be the primary environment for performing structured business analysis.

</details>

<details>
<summary><strong>04. 🔎 SQL Analysis</strong></summary>

The analysis focuses on transforming the prepared data into business insights by answering the analytical questions defined during the business-problem stage.
SQL techniques include:
- JOINS
- CASE Statements
- Aggregate functions
- Subqueries
- Common Table Expressions (CTEs)
- Window functions
</details>

<details>
<summary><strong>05. 📊 Power BI Dashboard</strong></summary>

The SQL database is then connected to Power BI to create an interactive business intelligence dashboard

Dashboard components include:
- KPI Cards
- Visualizations 
- Interactive features 

</details>

<details>
<summary><strong>06. 📝 Project Report</strong></summary>

The project findings are consolidated into a professional project report.
The report summarizes the analytical process, major findings, and business implications.

Report structure:
Executive Summary
A concise overview of:
- Business problem
- Analytical approach
- Key findings
- Business recommendations

</details>

<details>
<summary><strong>07. 🎤 Stakeholder Presentation</strong></summary>

The final stage of the project is to communicate the findings to stakeholders.
Gamma is used to create a professional presentation that converts the analytical results into a concise business story.

The presentation focuses on:
- Business Problem
       ↓
- What We Analyzed
       ↓
- What We Found
       ↓
- Why It Matters
       ↓
- What We Recommend
       ↓
- Expected Business Impact

</details>
